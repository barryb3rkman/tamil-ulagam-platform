# About page composition

## Purpose

The About page is a global institutional manifesto for Tamil Ulagam. It explains why the federation is being built, the fragmentation it intends to address, and the responsible long-term direction of the platform without claiming future capabilities are currently available.

## Sequence and content

The page moves from an editorial hero through a manifesto, vision and mission, four challenge statements, six core objectives, a staged ecosystem, governance principles, development path, Tamil cultural statement, and participation call to action. All substantive copy is maintained in the typed About content source.

## Media and visual treatment

The About hero uses the approved `aboutHero` registry entry as the sole priority image. The governance and roadmap sections use `partnerships` and `roadmapFuture` as lazy media. The page favours wide editorial compositions, numbered rules, asymmetrical panels, and restrained maroon and gold accents over repeated cards.

## Integrity and responsibility

The ecosystem is visibly labelled as building the foundation. Governance content establishes clear ownership, privacy-conscious design, controlled administration, honest communication, and responsible collaboration as future operating principles. No statistics, partner relationships, profiles, or service availability are implied.

## Responsive and accessible behaviour

Large-screen layouts balance concise copy with wide media. Narrow layouts convert every grid into a deliberate vertical sequence, keep Tamil type comfortably sized, preserve image proportions, and avoid horizontal overflow. The hero anchor uses an offset so the shared navigation does not conceal the vision and mission heading. Sections use semantic headings, labelled landmarks, registry alt text, and visible keyboard focus.

## Motion

The page relies on existing short CSS transitions for links, buttons, and image hover treatment. It has no animation dependency, autoplay, parallax, counters, or persistent motion.
